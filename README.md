## Описание

Опросник без сохранения в базу данных и доступа к статистике и результатам. История опросов сохраняется только локально в браузере для каждого пользователя. При смене браузера, очистке кэша история будет стерта.

Доступны 3 языка: русский, английский, монгольский

## Как подключить опросник

1.  Загрузить файлы из assets на хостинг/облако, чтобы были http ссылки на эти файлы

2.  Подключить файл стилей `style.min.css` и javascript-файл `app.min.js`. Через админку загрузить их для статьи, либо через облако загрузить оба файла и подключить по ссылке с облака.
    
3.  В html коде, к любому кликабельному элементу, надо добавить CSS класс `double-energy-poll-button`. Кнопка станет кликабельной и будет открывать опросник.
    
4.  Необязательные атрибуты кнопки:
    
    -   `data-logo="путь/к/nutrilite.svg"` — логотип в шапке опросника, взять ссылку на файл из облака, в которое загрузили файл на 1 шаге;
    -   `data-product="путь/к/double-energy-product.png"` — фото продукта на экране результата, взять ссылку на файл из облака, в которое загрузили файл на 1 шаге;
    -   `data-buy="https://…"` — ссылка на покупку, на сам продукт.
    
    Если `data-logo` не указан, шапка с логотипом не выводится. Если не указан `data-product`, на экране результата не выводится фото продукта (название остаётся). Если не указан `data-buy`, кнопки «Купить» нет, а фото и название не являются ссылкой.
